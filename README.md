# Lavindu Maneth Mathematics LMS

Next.js + Tailwind CSS interactive learning platform demo. Sample grades and lessons; no real authentication or payments.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm start
```

Deploy on Vercel with the Next.js preset. Teacher photo supplied by the user. Demo includes class filters, student dashboard, lesson selection, completion state, sample notes download, and a local-only payment slip preview. No file is uploaded. Replace illustrative grades and class details before production.
